QangPhi.from_complex requires unit modulus (atol=1e-6) and raises ValueError for \(z=2\); Qang.from_statevector instead accepts normalized amplitudes and removes the global phase by rotating \(\alpha\) to a non-negative real. There is no angular fidelity function in qecho: the inverse recovers the value in expectation but does not reduce the variance.

46.3 Metrological corrections

  1. \(5\sigma\) is an \(\alpha\) level, not a tolerance band. qfalsify.decide(k, n, p0, alpha) has no 5σ mode: use \(\alpha=2{,}8665\times10^{-7}\) (one-sided) or \(\alpha=5{,}7330\times10^{-7}\) (two-sided). For \(m\) comparisons, qfalsify.holm(pvalues, alpha) controls the family-wise error rate.
  2. The resolution table is polar. \(159{,}1549/\sqrt N\) must not be reused for the azimuth or the cone phase: the azimuth adds \(1/|\sin\theta|\) and diverges at \(\theta=0,\pi\); the cone uses the prefix \(500\), not \(159{,}1549\).
  3. Phase is a ratio, not a global amplitude. \(\beta/\alpha\) with \(|\cdot|=1\); the global phase is unobservable and is removed before building QangPhi.
  4. Readout correction has a price. With \(e_{01}=0{,}02\), \(e_{10}=0{,}06\), \(k=1-e_{01}-e_{10}=0{,}92\), the inverted series variance is amplified by \(k^{-2}=1{,}1815\).
  5. The F13/B3 interpretation stands. The experiment uses \(\theta=250\) qga, where \(|\sin\theta|=1\) and \(\sigma_\varphi=\sigma_\theta\); its \(\alpha=0{,}05\) belongs to the 600-estimate protocol, not to a \(5\sigma\) decision level.
