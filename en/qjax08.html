Chapter 8 — Coupling QAN to Probability Distributions: qg Moments, k-Local Truncation, Divergences and Shot Budget

Updated: November 15, 2026

Module: qang.qdist (JAX, jax<0.9; depends on qang.qan). Verification: tools/verify_cap08.py. Continues Ch. 7 (QAN/MI/IQAN); geometric phases and Fisher information move to Ch. 9–10 in BOOK_OUTLINE.md.

8.1 Every readout distribution is a vector of qg moments

For \(n\) qubits read in \(Z\), \(p(x)=|\langle x|\psi\rangle|^2\) admits the exact Walsh–Hadamard expansion in qang moments: \[p(x)=2^{-n}\sum_{S\subseteq[n]}qg_{Z_S}\,\chi_S(x),\qquad qg_{Z_S}=\langle Z_S\rangle=\sum_x p(x)\chi_S(x),\quad \chi_S(x)=\prod_{i\in S}z_i(x),\ z_i\in\{\pm1\}.\] \(qg_{Z_\emptyset}=1\); \(|S|=1\) are the \(qg_Z^{(q)}\) of Ch. 1; \(|S|=2\) the \(qg_{ZZ}^{(pq)}\) of Ch. 7. Parseval: \(\|p-r\|_2^2=2^{-n}\sum_S(\Delta qg_{Z_S})^2\). Convention: qubit \(q\leftrightarrow\) bit \(n-1-q\) of \(x\) and of \(S\) (big-endian), identical to qang.qan. The \(Z\)-readout distribution is exactly the Walsh transform of its qang moments; first- and second-order moments are the \(qg_Z\) and \(qg_{ZZ}\) of Chapters 1 and 7. Parseval links the \(L_2\) error in \(p\) to the \(L_2\) error in the moments (exact).

8.2 k-local truncation and shot bound

Keeping the \(M_k=\sum_{j\le k}\binom nj\) moments of order \(\le k\) gives the \(L_2\) projection \(p_{(k)}\) (it can be negative if \(k<n\): it is an estimator, not a distribution). Sampling-error bound (Cauchy–Schwarz + Parseval, exact): \[\mathbb E\big[\mathrm{TV}(\hat p,p)\big]\le\tfrac12\sqrt{M/N},\qquad M=\begin{cases}2^n-1&\text{full histogram}\\ M_k&\text{moments}\le k\end{cases}\] Since each \(\hat{qg}_{Z_S}\) has \(\mathrm{Var}\le1/N\) uniformly in \(S\), the budget for TV \(\le\varepsilon\) is \(N^\star=M/(4\varepsilon^2)\): the saving against the histogram is exactly \(1-M_k/(2^n-1)\) and it is paid for with the truncation bias \(\mathrm{TV}(p_{(k)},p)\), which does depend on the state (in verify_cap08.py §2: \(0.126\) for a random 4-qubit QAN layer; mixed). Keeping only \(k\)-local moments trades an exact, state-independent shot saving for a state-dependent truncation bias; both are reported, neither is hidden (exact bound, mixed bias).

8.3 Divergences in qg coordinates

\[D(qg_Z\|qg_Z')=\sum_{s=\pm}\tfrac{1+s\,qg_Z}{2}\log_2\frac{1+s\,qg_Z}{1+s\,qg_Z'}\ \text{[bit]},\qquad H^2(qg_Z,qg_Z')=1-\sqrt{p_0p_0'}-\sqrt{p_1p_1'}=1-\cos qg_L,\] with \(qg_L=|\theta-\theta'|/2\) the geodesic distance of Ch. 1 (common meridian, exact). In m-qg reading both are evaluated at \(m/1000\); the Fisher metric of \(D\) in \(qg_Z\) is \(qg_\kappa=1/(\ln2(1-qg_Z^2))\) (Ch. 1), which repeats the prohibition of flat descent in \(qg_Z\) (THEORY_CORE §2.1): every optimization of \(D\) or \(H^2\) in this chapter is done in qga.

8.4 Haar prior and Bayesian reading

\(p_0\sim\mathrm{Beta}(1,1)\Leftrightarrow qg_Z\sim\mathcal U[-1,1]\) (Ch. 4). Posterior after \(N\) shots with \(k_0\) zeros: \(\mathrm{Beta}(1+k_0,\,1+N-k_0)\), \[\mathbb E[qg_Z]=\frac{2(1+k_0)}{N+2}-1,\qquad \mathrm{Var}[qg_Z]=\frac{4(1+k_0)(1+N-k_0)}{(N+2)^2(N+3)}.\] At the equator (\(k_0=N/2\)): \(\sigma=1000/\sqrt{N+3}\) m-qg (\(31.58\) m-qg at \(N=1000\)), with no coverage collapse at the poles (exact).

8.6 JAX block (qang/qdist.py)

@partial(jax.jit, static_argnames=("n",))
def qg_moments(p, n):               # qg_{Z_S} = Σ_x p(x) χ_S(x), 2^n moments (exact)
    return _chi(n) @ p

@partial(jax.jit, static_argnames=("n",))
def probs_from_moments(q, n):       # exact inverse Walsh
    return (_chi(n).T @ q) / (2 ** n)

@partial(jax.jit, static_argnames=("n", "k"))
def truncate_k_local(p, n, k):      # L2 projection onto moments of order ≤ k
    q = jnp.where(moment_order(n) <= k, qg_moments(p, n), 0.0)
    return probs_from_moments(q, n)

@jax.jit
def hellinger2_qg(qz, qz2):         # 1 − cos(qg_L)
    p0, p0b = (1 + qz) / 2, (1 + qz2) / 2
    return 1.0 - jnp.sqrt(p0 * p0b) - jnp.sqrt((1 - p0) * (1 - p0b))

@jax.jit
def haar_posterior_qz(k0, N):       # (E[qg_Z], Var[qg_Z]) with Beta(1,1) prior
    a, b = 1.0 + k0, 1.0 + N - k0
    return 2 * a / (a + b) - 1, 4 * a * b / ((a + b) ** 2 * (a + b + 1))

def shots_tv_bound(n, M, tv):       # N* = M / (4 tv²)
    return M / (4.0 * tv ** 2)

# IQAN by moments (verify_cap08 §5): loss = Σ_{|S|≤2} (qg_S(QAN) − qg_S*)², descent in qga
vg = jax.jit(jax.value_and_grad(lambda th: loss_moments(th)))

tests/test_qdist.py

import pytest; jax = pytest.importorskip("jax")
import numpy as np, jax.numpy as jnp
from qang.qdist import qg_moments, probs_from_moments, hellinger2_qg, haar_posterior_qz, shots_tv_bound

def test_walsh_roundtrip():
    p = jnp.array(np.random.default_rng(0).dirichlet(np.ones(8)))
    assert np.allclose(probs_from_moments(qg_moments(p, 3), 3), p, atol=1e-14)

def test_hellinger_geodesic():
    th, th2 = 0.3, 1.9
    assert abs(float(hellinger2_qg(np.cos(th), np.cos(th2))) - (1 - np.cos(abs(th - th2) / 2))) < 1e-14

def test_haar_posterior_equator():
    m, v = haar_posterior_qz(jnp.array(50.0), jnp.array(100.0))
    assert abs(float(m)) < 1e-14 and abs(float(v) - 1 / 103) < 1e-14

def test_shots_bound():
    assert abs(shots_tv_bound(8, 36, 0.05) - 3600.0) < 1e-6
