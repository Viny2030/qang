Chapter 7 — Quantum Angular Networks (QAN), Mutual Information in qang Space and Regularized Inversion (IQAN)

Analysis and update date: November 22, 2026

Module: qang.qan (optional JAX backend, jax<0.9; NumPy core untouched). Verification: tools/verify_cap07.py. Position in BOOK_OUTLINE.md: new Ch. 7 (Part II); geometric phases and Fisher information move to 8–9, or merge into Ch. 23 (editorial decision pending).

7.1 QAN: the network as a qga → qg map

A QAN is a differentiable map \(\Phi:\mathbb{R}^P_{\text{qga}}\to[-1,1]^n\times[-1,1]^{n\times n}\) that sends angular parameters (scale qga, \(\theta=2\pi\,\alpha/1000\)) to projective readings in a single \(Z\) basis. Canonical layer: \[|\psi(\boldsymbol\alpha,\boldsymbol\beta,\boldsymbol\gamma)\rangle=\Big[\bigotimes_q R_Y(\gamma_q)\Big]\Big[\prod_{(p,q)\in E}R_{ZZ}(\beta_{pq})\Big]\Big[\bigotimes_q R_Y(\alpha_q)\Big]|0\rangle^{\otimes n},\qquad \alpha,\beta,\gamma\ \text{in qga}.\] Reading: \(qg_Z^{(q)}=\langle Z_q\rangle\), \(qg_{ZZ}^{(pq)}=\langle Z_pZ_q\rangle\), both from the same histogram \(|\psi|^2\). Every \(qg_Z^{(q)}\) and every pairwise correlator \(qg_{ZZ}^{(pq)}\) comes from one histogram; no ancilla, no extra two-qubit gate, no basis change. \(R_{ZZ}\) has period \(500\) qga in the reading: \(R_{ZZ}(\beta+500)=-i\,Z\!\otimes\!Z\,R_{ZZ}(\beta)\) and the factor \(Z\!\otimes\!Z\) is absorbed as a virtual \(R_Z(\pi)\) (\(\gamma\to-\gamma\)), invisible in \(|\psi|^2\) (Ch. 2, exact).

7.2 MI in qang space

The joint \(Z\) distribution of a pair is the exact inversion of its Pauli expansion: \[p_{ab}(s,t)=\tfrac14\big(1+s\,qg_Z^{(a)}+t\,qg_Z^{(b)}+st\,qg_{ZZ}^{(ab)}\big),\quad s,t\in\{+1,-1\}.\] Mutual information (bits): \[I_Z(a;b)=qg_S^{(a)}+qg_S^{(b)}-H(p_{ab}),\qquad qg_S=H\!\big(\tfrac{1+qg_Z}{2}\big),\qquad 0\le I_Z\le\min\big(qg_S^{(a)},qg_S^{(b)}\big)\le1.\] Three qang numbers (\(qg_Z^{(a)},qg_Z^{(b)},qg_{ZZ}^{(ab)}\)) determine \(I_Z\). Limit (THEORY_CORE §2.4, against): \(I_Z\) depends on the \(Z\) basis and is not an entanglement measure (a rotated product state can give \(I_Z=0\) with maximal entanglement and vice versa). Its legitimate use is classical: deciding which pairs are worth coupling in a given layer and how many shots it costs to estimate them.

Shot budget (delta method, asymptotically exact): with \(\Sigma=\mathrm{diag}(p)-pp^\top\) and \(g=\partial I_Z/\partial p\), \[\mathrm{Var}(\hat I_Z)\simeq\frac{g^\top\Sigma g}{N},\qquad N^\star(\sigma_I)=\frac{g^\top\Sigma g}{\sigma_I^2}.\] At \(I_Z=0\) the gradient \(g\) vanishes and the estimator is biased at second order (\(\mathbb E[\hat I_Z]\approx 1/(2N\ln2)\) bits for the \(2\times2\) table, Miller–Madow): use a threshold \(\tau>1/(2N\ln 2)\) in every pruning. The shot cost is planned by the delta method with \(g\) obtained by automatic differentiation.

7.3 IQAN: regularized inversion in angle

Given a target \((qg_Z^{\star},I^{\star})\), IQAN solves \[\min_{\boldsymbol\alpha,\boldsymbol\beta,\boldsymbol\gamma\in\text{qga}}\ \mathcal L=\big\|qg_Z-qg_Z^{\star}\big\|_2^2+\lambda\sum_{(p,q)\in E}\big(I_Z^{(pq)}-I^{\star}_{pq}\big)^2+\mu\sum_{(p,q)\in E}\Big(\frac{\beta_{pq}}{500}\Big)^2 .\] The descent is Euclidean in angle (qga): by THEORY_CORE §2.1 it is first-order equivalent to the step damped by \(qg_\kappa\) in \(qg_Z\) and avoids the polar divergence of flat descent in \(qg_Z\) (0/20, against). The \(\mu\) term is minimum-area compilation: it penalizes \(|\beta|\) and, because of the 500 qga period, the minimum of a maximal entangler falls at \(\beta=250\) qga. Learning rate: \(\eta_{\text{qga}}=\eta_{\text{rad}}\,(1000/2\pi)^2\) (exact rescaling, no effect on barren plateaus, §2.1).

7.5 JAX block (qang/qan.py, jax<0.9)

import jax, jax.numpy as jnp
from functools import partial
jax.config.update("jax_enable_x64", True)
RAD_PER_QGA = 2.0 * jnp.pi / 1000.0          # qga -> rad (exact)

def _h2(p):                                   # qg_S in bits, 0·log0 = 0
    p = jnp.clip(p, 1e-300, 1.0); q = jnp.clip(1.0 - p, 1e-300, 1.0)
    return -(p * jnp.log2(p) + q * jnp.log2(q))

@jax.jit
def joint_probs_qg(qz_a, qz_b, qzz):
    """p(s,t) = (1 + s qz_a + t qz_b + s t qzz)/4, order 00,01,10,11."""
    s = jnp.array([1., 1., -1., -1.]); t = jnp.array([1., -1., 1., -1.])
    return (1.0 + s * qz_a + t * qz_b + s * t * qzz) / 4.0

@jax.jit
def mutual_information_qg(qz_a, qz_b, qzz):
    """I_Z(a;b) [bit] = qg_S(a) + qg_S(b) - H(p_ab). Z basis: does not measure entanglement."""
    p = jnp.clip(joint_probs_qg(qz_a, qz_b, qzz), 1e-300, 1.0)
    return _h2((1 + qz_a) / 2) + _h2((1 + qz_b) / 2) + jnp.sum(p * jnp.log2(p))

@jax.jit
def mi_shot_variance_qg(qz_a, qz_b, qzz):
    """N·Var(Î) by the delta method: gᵀ(diag p − p pᵀ)g, g = ∂I/∂p via jax.grad."""
    def mi_of_p(p):
        p = jnp.clip(p, 1e-300, 1.0)
        return _h2(p[0] + p[1]) + _h2(p[0] + p[2]) + jnp.sum(p * jnp.log2(p))
    p = joint_probs_qg(qz_a, qz_b, qzz); g = jax.grad(mi_of_p)(p)
    return g @ (jnp.diag(p) - jnp.outer(p, p)) @ g

@partial(jax.jit, static_argnames=("n",))
def qan_readout(psi, n):
    """qg_Z[q] and qg_ZZ[q,r] from |psi|² (a single basis)."""
    p = jnp.abs(psi) ** 2; idx = jnp.arange(2 ** n)
    z = jnp.stack([1.0 - 2.0 * ((idx >> (n - 1 - q)) & 1) for q in range(n)])
    return z @ p, (z * p) @ z.T

@partial(jax.jit, static_argnames=("n",))
def mi_matrix_qg(qz, qzz, n):
    f = jax.vmap(jax.vmap(mutual_information_qg, (None, 0, 0)), (0, None, 0))
    return f(qz, qz, qzz)

def iqan_loss(params, target_qz, target_mi, n, pairs, lam=1.0, mu=1e-3):
    """||qg_Z−qg_Z*||² + λΣ(I_Z−I*)² + μΣ(β/500)²; Euclidean gradient in qga."""
    a, b, g = params[:n], params[n:n + len(pairs)], params[n + len(pairs):]
    qz, qzz = qan_readout(qan_state(a, b, g, n, pairs), n)
    loss = jnp.sum((qz - target_qz) ** 2) + mu * jnp.sum((b / 500.0) ** 2)
    for k, (p, q) in enumerate(pairs):
        loss += lam * (mutual_information_qg(qz[p], qz[q], qzz[p, q]) - target_mi[k]) ** 2
    return loss

vg = jax.jit(jax.value_and_grad(iqan_loss), static_argnames=("n", "pairs"))
# loop: params -= lr_qga * grad, with lr_qga = lr_rad * (1000/2π)² ≈ 2.5e3 for lr_rad = 0.1

qan_state (RY–RZZ–RY in qga, jnp.complex128 statevector) and iqan_fit are in the attached file qan_jax.py.

tests/test_qan.py

import pytest; jax = pytest.importorskip("jax")
import jax.numpy as jnp, numpy as np
from qang.qan import mutual_information_qg, joint_probs_qg, mi_shot_variance_qg, qan_state, qan_readout

def test_product_zero_mi():
    assert abs(float(mutual_information_qg(0.3, -0.6, -0.18))) < 1e-12

def test_joint_probs_sum_and_marginals():
    p = np.asarray(joint_probs_qg(0.2, -0.3, 0.5))
    assert abs(p.sum() - 1) < 1e-15 and abs((p[0]+p[1]) - 0.6) < 1e-15

def test_bell_one_bit():
    psi = qan_state(jnp.array([250., 250.]), jnp.array([250.]), jnp.array([250., -250.]), 2, ((0, 1),))
    qz, qzz = qan_readout(psi, 2)
    assert abs(float(mutual_information_qg(qz[0], qz[1], qzz[0, 1])) - 1) < 1e-10

def test_delta_variance_positive():
    assert float(mi_shot_variance_qg(0.2, -0.3, 0.5)) > 0
