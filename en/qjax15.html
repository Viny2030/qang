Chapter 15 — Optical Teleportation and the Bell-Pair Limit: the Channel as a Linear m-qg Contraction and the 333 m-qg Threshold

Updated: November 15, 2026

Rewrite of the old Ch. 12 on the basis of Ch. 1–14. Module: qang.qtele (JAX, jax<0.9; aligned with qang.qpon, §57, §157). Verification: tools/verify_cap15.py. Dual rail and sector filter at long distance: Ch. 16.

15.1 The Werner resource read in three correlators

\(\rho_V=V|\Phi^+\rangle\langle\Phi^+|+(1-V)\tfrac{I}{4}\) has \(qg_{XX}=V\), \(qg_{YY}=-V\), \(qg_{ZZ}=V\) (Ch. 7: single-basis correlators each, 0 ancillas). Singlet fraction and mean teleportation fidelity (Horodecki): \[F_s=\tfrac14\big(1+qg_{XX}-qg_{YY}+qg_{ZZ}\big),\qquad \bar F=\frac{2F_s+1}{3},\qquad \bar F_{\text{Werner}}=\frac{1+V}{2}.\] Classical threshold \(\bar F=2/3\iff F_s=1/2\iff V=1/3\): the Bell pair is useful if and only if \(qg_{ZZ}>333\) m-qg under the Werner model (exact). For a general resource all 3 bases are needed; the single-basis reading is an upper bound (§15.4). The Werner resource is read as three single-basis correlators; the classical threshold is \(qg_{ZZ}=333\) m-qg under the Werner model, and an upper bound otherwise.

15.2 The teleportation channel in m-qg: m’=V m

Full teleportation (Bell measurement on input⊗A, Pauli correction on B) with resource \(\rho_V\) is the depolarizing channel \(\mathbf r\mapsto V\mathbf r\); in readout: \(m\text{-qg}'=V\cdot m\text{-qg}\) for any axis, verified to \(10^{-13}\) on random inputs. Example: \(+600\) m-qg \(\to+420\) (\(V=0.7\)) \(\to+200\) (\(V=1/3\)). The dissipative deficit of the teleported state (Ch. 5) is \(qg_\tau=\sqrt{1-V^2r^2}\). The average fidelity over the 2-design of 6 Pauli eigenstates reproduces \((1+V)/2\) to \(10^{-13}\) (exact).

15.3 Shot budget and configurations

From \(qg_{ZZ}\): \(\sigma_{\bar F}=\tfrac12\sqrt{(1-V^2)/N}\) ⇒ \(N=(1-V^2)/(4\sigma_{\bar F}^2)\): \(475\) shots (\(V=0.9\)) or \(1\,600\) (\(V=0.6\)) for \(\sigma_{\bar F}=0.01\) in one configuration. Process tomography of the channel: 4 inputs \(\times\) 3 bases \(=12\) configurations, \(\ge12N\) shots for the same precision per cell (exact, count).

15.4 mixed finding: the single-basis reading overestimates non-Werner resources

A resource with pure dephasing (\(qg_{ZZ}=1\), \(qg_{XX}=0.8\)): real \(\bar F\) (3 bases) \(=0.9333\); \(\bar F\) assuming Werner from \(qg_{ZZ}\) \(=1.0000\) (bias \(+0.067\)). Rule: certify with 3 bases; plan with 1. A resource with \(qg_{ZZ}>1/3\) but \(qg_{XX}+qg_{ZZ}\le1\) is not certified as entangled (2-basis witness, Ch. 5).

15.6 JAX block (qang/qtele.py)

@jax.jit
def resource_correlators(rho2):                 # (qg_XX, qg_YY, qg_ZZ)
    f = lambda P: jnp.real(jnp.trace(rho2 @ jnp.kron(P, P)))
    return f(X), f(Y), f(Z)

@jax.jit
def singlet_fraction_from_qg(qxx, qyy, qzz):    # (1 + qg_XX − qg_YY + qg_ZZ)/4
    return (1.0 + qxx - qyy + qzz) / 4.0

@jax.jit
def teleport_fidelity_from_singlet(Fs):         # (2F_s + 1)/3 ; threshold 2/3
    return (2.0 * Fs + 1.0) / 3.0

def teleport(rho_in, rho_res):                  # Bell measurement + Pauli correction, ρ_out 2×2
    rho = kron(rho_in, rho_res); corr = [I2, Z, X, X @ Z]; out = 0
    for k, b in enumerate(bell_basis()):
        M = kron(jnp.outer(b, jnp.conj(b)), I2)
        rb = jnp.einsum("iaib->ab", (M @ rho @ M).reshape(4, 2, 4, 2))
        out = out + corr[k] @ rb @ jnp.conj(corr[k]).T
    return out

def shots_for_fidelity(V, sigma_F):             # (1 − V²)/(4σ_F²)
    return (1.0 - V ** 2) / (4.0 * sigma_F ** 2)

tests/test_qtele.py

import pytest; jax = pytest.importorskip("jax")
import numpy as np, jax.numpy as jnp
from qang.qtele import werner, teleport, bloch, state_from_bloch, teleport_fidelity_werner_qzz, resource_correlators

def test_channel_contracts_bloch():
    r = jnp.array([0.3, -0.4, 0.5]); out = teleport(state_from_bloch(r), werner(0.7))
    assert np.allclose(np.asarray(bloch(out)), 0.7 * np.asarray(r), atol=1e-13)

def test_classical_threshold_333_mqg():
    assert abs(float(teleport_fidelity_werner_qzz(1 / 3)) - 2 / 3) < 1e-15

def test_werner_correlators():
    qxx, qyy, qzz = resource_correlators(werner(0.5))
    assert abs(float(qxx) - 0.5) < 1e-14 and abs(float(qyy) + 0.5) < 1e-14 and abs(float(qzz) - 0.5) < 1e-14
