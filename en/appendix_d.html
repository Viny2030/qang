Appendix D — Quick reference of the qang 0.13.1 API

This is the list of every module of the qang package at version 0.13.1, with its public names: those in __all__ or, if the module does not define it, the public functions and classes it declares. tools/make_appendices.py generates it by importing each module, so the list is the code’s own and not a copy. The signature and documentation of each name are in help(qang.<module>.<name>).

  • import qang needs only NumPy. The SDK modules (qiskit_gate, cirq_gate, pennylane_gate, ibm, qiskit_ml, qec, circuits, algorithms) and those of qang.integrations import their library when used.
  • There is no crypto module: the book’s cryptography is in the examples (Chapters 16–18). qang.iqm needs iqm-client, which pins its own Qiskit: it goes in a separate environment (qang[iqm]).
  • The “names” column gives the number of public names, and the full list follows the table.
