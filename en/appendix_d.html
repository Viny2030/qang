Appendix D — Quick reference of the qang 0.16.0 API

This is the list of every module of the qang package at version 0.16.0, with its public names: those in __all__ or, if the module does not define it, the public functions and classes it declares. tools/make_appendices.py generates it by importing each module, so the list is the code’s own and not a copy. The signature and documentation of each name are in help(qang.<module>.<name>).

  • import qang needs only NumPy. The SDK modules (qiskit_gate, cirq_gate, pennylane_gate, ibm, qiskit_ml, qec, circuits, algorithms) and those of qang.integrations import their library when used.
  • There is no crypto module: the book’s cryptography is in the examples (Chapters 16–18). qang.iqm needs iqm-client, which pins its own Qiskit: it goes in a separate environment (qang[iqm]).
  • The “names” column gives the number of public names, and the full list follows the table.

Could not be imported in the script’s environment: qan, qbattery, qchem, qctc, qdemarc, qdist, qdualrail, qdynamics, qfisher, qgeom, qkd, qkernels, qmajorana, qmetro, qneutrino, qrng, qscramble, qsymfilter, qtele, qweightqnn.

D.3 Update for the rewrite (Chapters 7–44)

The “chapter N” references in this appendix use the numbering of cap01.qmd–cap36.qmd. The rewrite (Parts III–XIV, qjax07–qjax44) uses the new numbering: 1–6 unchanged; 7–29 shift by +3 (7–9 are new); 30–35 shift by +4; 33 and 42 are string theory; 43 and 44 are robotics and agentic AI.

The module table is regenerated by tools/make_appendices.py, which reads the code; the rewrite’s modules (qan, qdist, qfisher, qcft, qanti, qtimeloop, qstring, qrobot, qagent, qlimits, qgarnet, qarch, qnano, qtransv, qintegr, qledger, qfalsify, qchar, qecc, qchem) appear there with their public names. qang.qarch checks by code that import qang needs only NumPy (Ch. 36) and qang.qintegr that the 12 integrations are imported behind a guard (Ch. 39).
