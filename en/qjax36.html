Chapter 36 — Software Architecture and the Multi-SDK Ecosystem: What Each Module Requires, What CI Installs, and What a Wrong Qubit Order Costs

Día de análisis y actualización: 23 de noviembre de 2026

Analysis and update date: November 23, 2026

Rewrite of the architecture chapter on the basis of Ch. 1–35. Module: qang.qarch (standard library only; convention_error_mqg uses qang.interop). Verification: tools/verify_cap36.py, which audits the real repository. Summary: the qang core requires only NumPy (48 of 79 modules); the rest is activated by extras; the qubit order across SDKs is unified in qang.interop, and getting it wrong costs up to 600 m-qg without raising an error. Abstract. An AST audit of the real repository: 48 of 79 modules need only NumPy; 20 need JAX, 9 Qiskit, 1 Cirq, 1 PennyLane. The CI installs .[all], which includes neither JAX nor Torch, and none of the 203 test files imports a module requiring a missing package without an importorskip guard. Reading counts with the wrong qubit-order convention shifts the \(qg_Z\) profile by up to 600 m-qg without an error.

36.1 Reading rules

  1. Every claim about the architecture comes from tools/verify_cap36.py run on the repository, not from memory. The verifier fails if the repository stops satisfying it.
  2. m-qg \(=1000\,qg_Z\); qga is the angular scale (1 turn = 1000 qga).
  3. What comes from stored IBM runs (§137–§150) is cited and marked unverified here: it was not re-run.

36.2 What each module requires to import

requires walks the syntax tree of every qang module, takes only the module-level imports (deferred ones, inside functions, do not count) and adds those of the qang modules it imports, transitively:

group modules packages required
core 48 NumPy and standard library
JAX 20 jax: qan, qbattery, qchem, qctc, qdemarc, qdist, qdualrail, qdynamics, qfisher, qgeom, qkd, qkernels, qmajorana, qmetro, qneutrino, qrng, qscramble, qsymfilter, qtele, qweightqnn
Qiskit 9 qiskit: algorithms, ansatze, circuits, ibm, iqm, qec, qiskit_gate, qml, sectors
Cirq 1 cirq_gate
PennyLane 1 pennylane_gate

No module requires SciPy on import. This was not the case: qang.qchar (Ch. 30) imported scipy.linalg and scipy.optimize at module level, and SciPy is only in the examples and dev extras. Ch. 36 detected it and it was fixed: the matrix exponential was a diagonal of phases and the unimodal minimum is solved by golden-section search; tools/verify_cap30.py and its 5 tests still pass with the same numbers.

36.3 Extras and what CI installs

parse_pyproject reads pyproject.toml with no external dependencies, and check_extras checks the three project rules:

  • the core depends only on numpy;
  • iqm is isolated from all (because iqm-client pins its own Qiskit);
  • the jax extra is bounded to <0.9.

CI installs pip install -e ".[all]": 14 packages, among them Qiskit, Cirq, PennyLane, scikit-learn and SciPy, but not JAX or Torch. Therefore every test that imports a module of the JAX group must be protected with pytest.importorskip("jax"): an unguarded import fails at collection and pytest exits with code 2, not 1. unguarded_tests computes, for each test file, the packages it requires (its own, those of the qang.x it imports and those of the examples/ scripts it imports, transitively) and returns those that are neither installed nor guarded:

  • of 203 test files: 0 unprotected.

This result rules out one cause of the Tests failure in CI; it does not identify the real cause. That remains pending from the log of the “Run tests” step.

36.4 A single qubit order

Qiskit writes qubit 0 on the right of the bit string; Cirq, PennyLane, Braket and pytket write it first. qang.interop.canonical_counts brings everything to \(\{(b_0,\dots,b_{n-1}):\text{count}\}\). With a product state of \(qg_Z=[0.6,-0.2,0.0]\) per qubit (10⁶ exact shots):

  • Qiskit ('001'-style) and Cirq ('100'-style) give the same canonical result;
  • reading Qiskit counts as if they were Cirq’s shifts the profile by up to 600.0 m-qg (qubit 0 becomes qubit 2);
  • with a symmetric register (000/111) the shift is 0.0 m-qg: the error is not seen exactly where everything seems fine. That is why the order is declared with sdk= and canonical_counts rejects a dictionary without it.

36.6 Guidelines by hardware type

  • Superconducting (IBM, IQM): compile with weight-conserving gates (XX+YY, RBS) and check it with qang.qlimits.preserves_weight or the analysis of qang.ibm; compare two-qubit gates at the same optimization level (Ch. 35); correct the readout with the calibration or with the two poles.
  • Ions (IonQ, Braket): all-to-all connectivity; the bit order is resolved in qang.interop. The H₂ run on the real machine was rejected before a job was accepted and was not charged.
  • On any platform: rehearse for free, measure the cost with a small test, pre-register before the main job (Ch. 31), read the token from an environment variable and do not spend without an explicit flag.

from qang.qarch import parse_pyproject, check_extras, installed_by, requirement_root
def test_pyproject_and_requirement_roots():
    t = '[project]\ndependencies = [\n "numpy>=1",\n]\n[project.optional-dependencies]\njax = [\'jax[cpu]>=0.4,<0.9; python_version >= "3.10"\']\n' \
        'iqm = ["iqm-client[qiskit]>=36"]\nall = ["scikit-learn>=1.2", "qiskit>=1"]\n[project.urls]\nx = "y"\n'
    e = parse_pyproject(t)
    assert requirement_root("scikit-learn>=1.2") == "sklearn" and installed_by(e, "all") == {"numpy", "sklearn", "qiskit"}
    assert all(check_extras(e).values())

F12 — Quantum Ecosystem: the Same qga Phase in Qiskit, PennyLane and Cirq

F12 — Ecosistema cuántico: la misma fase qga en Qiskit, PennyLane y Cirq

Hypothesis H12 (unverified). The angular phase of a parametric gate reads identically in qga across the three installed SDKs. Agreement is shown here at statevector level; no speed, fidelity or hardware advantage is claimed.

Theorem T12 (exact). For \(|+\rangle\) followed by \(RZ(\varphi)\), the Bloch vector is \((\cos\varphi,\sin\varphi,0)\) and azimuth_qga satisfies \(\phi_{\mathrm{qga}}=\varphi\,1000/(2\pi)\). It is invariant under \(q_X,q_Y\to\lambda q_X,\lambda q_Y\) with \(\lambda>0\), and qecho.invert_readout recovers the unbiased value. All three conventions use \(RZ(\varphi)=\exp(-i\varphi Z/2)\).

Circuit design. One qubit, \(\varphi=125\) qga, \(N=65536\) shots, seed=21 and \(M=600\) estimates. Real statevectors: qiskit.quantum_info.Statevector, pennylane.state and cirq.final_state_vector; readout with qang.geometric.bloch_from_state, qga.azimuth_qga, QangPhi.from_complex, qecho.invert_readout and qang.qfalsify.decide/binom_upper (exact; tools/verify_exp_f12.py). SHA-256 preregistration 44e9bbfc85602d6891654b22a2d89f8b962ad6e3157232fd17ff9a282e128682, computed before measuring.

Quantitative falsification criterion. \(\sigma=0.621699\) qga, \(\delta_{5\sigma}=3.108\) qga, \(p_0=0.006216\), \(\alpha=0.05\). The three azimuths must agree with \(125\) qga within \(10^{-3}\) qga and the maximum Bloch deviation stay below \(10^{-6}\); sampling requires 600/600 hits and a +50 qga control with 0/600 and decision refutada (simulado).
